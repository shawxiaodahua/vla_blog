# WAM 世界行动模型调研

WAM（World Action Model）世界行动模型是具身智能的前沿方向，通过构建世界模型来预测环境变化并规划动作。

## 路线总览

- **联合 · 自回归**：自回归方式联合建模世界与动作
- **联合 · 扩散**：扩散方式联合建模
- **联合 · 混合**：混合多种生成范式的联合模型

## 代表模型

- Cosmos 3（NVIDIA）：全模态世界模型
- GR00T N2（NVIDIA）：通用机器人基础模型
- DreamZero：零样本策略世界模型
- WorldVLA：自回归动作世界模型
- Qwen-RobotWorld：视频世界模型
