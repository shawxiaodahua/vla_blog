# VLA 视觉-语言-动作模型发展深度调研报告

VLA（Vision-Language-Action）模型是具身智能的核心技术路线，将视觉感知、语言理解和动作生成统一到一个端到端框架中。

## 路线总览

本站按照方法论路线组织 VLA 模型细读：

- **离散 token**：将动作离散化为 token，使用类语言模型范式训练
- **连续 · 扩散/流匹配**：在连续动作空间使用扩散或流匹配生成
- **混合 · 连续回归**：混合离散与连续表示的回归方法
- **分层 · 双系统/推理**：快慢双系统架构，引入推理增强
- **新范式探索**：突破现有框架的新方法论
- **跨范式 · 基座/平台/仿真**：跨方法论的平台与仿真基础设施
